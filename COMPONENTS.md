# 🚀 Bibliotecas de Animação para JavaScript e React

Este documento reúne algumas das principais bibliotecas utilizadas para criar animações em aplicações web, desde animações simples de interface até experiências altamente interativas.

---

## 🌱 React Spring

**Site Oficial:** https://www.react-spring.dev/

### O que é?

O **React Spring** é uma biblioteca de animações baseada em física (Spring Physics) para React. Em vez de definir duração e curvas de animação, você define o estado inicial e o estado final, enquanto a biblioteca calcula um movimento natural.

### Principais características

- Animações suaves e naturais.
- Baseado em física.
- Excelente integração com React.
- Fácil de combinar com Hooks.

### Ideal para

- Transições de componentes.
- Modais.
- Menus.
- Cards.
- Dashboards.
- Interfaces modernas.

---

## 🎬 Motion (Framer Motion)

**Site Oficial:** https://motion.dev/

### O que é?

O **Motion** (antigo Framer Motion) é atualmente uma das bibliotecas de animação mais populares para React.

Permite criar animações extremamente complexas com poucas linhas de código.

### Principais características

- API muito simples.
- Layout Animations.
- Gestos (drag, hover, tap).
- Scroll Animations.
- Shared Layout.
- Excelente performance.

### Ideal para

- Landing Pages.
- Aplicações React.
- Dashboards.
- Sites modernos.
- Microinterações.

---

## ✨ Anime.js

**Site Oficial:** https://animejs.com/

### O que é?

O **Anime.js** é uma biblioteca JavaScript extremamente leve para criar animações em praticamente qualquer elemento.

Ela não depende de React.

Pode animar:

- CSS
- SVG
- Objetos JavaScript
- Canvas
- Atributos HTML

### Principais características

- Muito pequena.
- Fácil de aprender.
- Timeline poderosa.
- Excelente documentação.

### Ideal para

- Sites institucionais.
- Landing Pages.
- Logos animados.
- SVG.
- Canvas.

---

## ⚡ GSAP (GreenSock Animation Platform)

**Site Oficial:** https://gsap.com/

### O que é?

O **GSAP** é considerado o padrão da indústria quando falamos em animações para web.

É extremamente poderoso, rápido e utilizado por grandes empresas como:

- Google
- Apple
- Microsoft
- Adobe
- Nike

### Principais características

- Performance excepcional.
- Controle total da animação.
- Timelines extremamente avançadas.
- ScrollTrigger.
- MorphSVG.
- Draggable.
- SplitText.
- MotionPath.

### Ideal para

- Landing Pages Premium.
- Sites 3D.
- Experiências imersivas.
- Portfólios.
- Storytelling.
- Efeitos cinematográficos.

# 🏆 Qual escolher?

### Escolha **React Spring** se:

- Você usa React.
- Quer animações naturais.
- Precisa de transições elegantes.

---

### Escolha **Motion** se:

- Quer desenvolver interfaces modernas rapidamente.
- Deseja animações simples e avançadas.
- Procura excelente integração com React.

---

### Escolha **Anime.js** se:

- Não utiliza React.
- Quer uma biblioteca leve.
- Precisa animar SVG, Canvas ou CSS facilmente.

---

### Escolha **GSAP** se:

- Quer o máximo de controle.
- Desenvolve experiências visuais avançadas.
- Precisa de animações profissionais.
- Vai criar efeitos com scroll, timelines e storytelling.
